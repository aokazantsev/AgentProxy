# Отложенные идеи (после 1.0)

В план до 1.0 (`CLAUDE.md`) не входят. Берутся по решению пользователя.

## Подключение как в Charles

На телефоне в настройках Wi-Fi указываются IP ПК и порт прокси; затем сертификат по QR-коду со страницы монитора,
адрес — служебный хост прокси (`mitm.it`), потому что прокси на телефоне уже задан.

Решить до начала:

- прокси слушает сеть, а не только `127.0.0.1` (выключатель «слушать сеть», фильтр клиентов);
- входящее правило брандмауэра требует прав администратора;
- `adb reverse` остаётся вторым способом.
